# Автотесты для API Яндекс Диска

Репозиторий содержит пример интеграционного проекта автотестов для проверки базовых методов REST API сервиса Яндекс Диск. Задание выполнено в рамках отклика на стажировку в команду автоматизации тестирования Яндекса.

## О проекте
Тесты проверяют корректность обработки HTTP-запросов к ресурсам облачного хранилища. Проект спроектирован по канонам паттернов автоматизации с возможностью безопасной передачи авторизационных данных.

## Стек технологий
* **Язык:** Python 3
* **Тестовый фреймворк:** PyTest
* **Сетевой клиент:** Requests

## Структура веток (Git Flow)
* `main` — стабильная релизная ветка с описанием архитектуры.
* `develop` — ветка разработки, содержащая актуальный исходный код тестов и конфигурационные файлы зависимостей.
